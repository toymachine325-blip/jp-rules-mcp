🤖 AIエージェントに接続する人向け（MCP / REST API設定）

Claude Desktop や Antigravity 等のAIエージェントから直接このストアを呼び出す設定です。
AIに以下のMCP設定を登録すると、AI自らが商品一覧を確認し、許可されたお小遣いの範囲内で自律調達します。

Claude Desktop 設定例 (`claude_desktop_config.json`)
{ "mcpServers": { "souon-store": { "url": "http://localhost:3456/mcp", "headers": { "Authorization": "Bearer <発行されたお小遣いキー>" } } } }
curl による直接購入コマンド例
curl -X POST http://localhost:3456/api/purchase \ -H "Authorization: Bearer <APIキー>" \ -H "Content-Type: application/json" \ -d '{"product_id": "drums-8beat-midi"}'
